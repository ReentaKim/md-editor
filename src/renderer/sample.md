# MD Editor 문법 예제

왼쪽에서 편집하면 오른쪽 미리보기가 **실시간**으로 바뀝니다. *기울임*, ~~취소선~~, `인라인 코드`, [링크](https://commonmark.org)를 지원합니다.

> 팁: `⌘1` 편집기만 · `⌘2` 분할 · `⌘3` 미리보기만 · `⌘\` 사이드바

## 목록과 체크리스트

- 글머리 목록
  - 들여쓴 항목
1. 번호 목록
2. 두 번째

- [x] 미리보기에서 체크박스를 누르면
- [ ] 원본 마크다운의 `[ ]` / `[x]`가 바뀝니다

## 표

| 기능 | 단축키 | 비고 |
| --- | :---: | --- |
| 굵게 | ⌘B | 선택한 글자를 `**`로 감쌈 |
| 링크 | ⌘K | `[텍스트](주소)` |
| 표 삽입 | ⌥⌘T | 3열 표 템플릿 |
| 미리보기만 보기 | ⌘3 | ⌘1 편집기만 · ⌘2 분할 |

## 코드

```js
function greet(name) {
  // 코드 블록에 마우스를 올리면 복사 버튼이 나타납니다
  return `안녕하세요, ${name}님`;
}
```
